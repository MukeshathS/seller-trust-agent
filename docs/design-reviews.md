# Design reviews

Three independent AI reviews of the design and write-up, each from a different angle. Do not accept a comment automatically — record why each important one was accepted or rejected.

## 1. Practitioner review

Ask the reviewer to find: unrealistic assumptions, missing users or stakeholders, deployment risks, actions that can cause harm, actions that cause unnecessary work.

Status: not started

## 2. Probability review

Ask the reviewer to check: hidden states, prior probabilities, likelihood estimates, decision thresholds, error costs, calibration, and evidence for an alternative explanation.

Status: not started

## 3. Preprint review

Ask the reviewer to check: clear problem statement, new information, correct methods, test design, baseline quality, repeatable results, limitations, ethics, claims without evidence, questions for the next version.

Status: not started
